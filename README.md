# 🎵 찬양팀 콘티 도우미 (Praise Helper WebApp)

찬양팀의 원활한 합주와 예배 인도를 지원하는 **반응형 웹 애플리케이션(Web App)**입니다.  
악보 이미지의 무손실 키 체인지(전조), 세션 가이드 하이라이트(드럼 in, 브레이크 등), 콘티 큐 관리 및 연주자용 풀스크린 슬라이드 쇼를 지원합니다.

---

## 🎹 핵심 기능

### 1. 무손실 키 체인지 (코드 치환)
- **100% 원본 해상도 보존**: 업로드된 악보 이미지를 브라우저 캔버스를 통해 픽셀 손실 없이 렌더링합니다.
- **인페인팅 & 코드 치환**: 악보의 원래 배경색을 스마트 샘플링하여 기존 코드를 깨끗이 지우고, 화성학 전조 엔진에 의해 계산된 새 코드를 선명한 `Jua` 글꼴로 치환합니다.
- **12개 키 셀렉터**: C, Db, D, Eb, E, F, F#, G, Ab, A, Bb, B 및 `+1 반음(♯)`, `-1 반음(♭)` 컨트롤 지원.
- **분수 코드(Slash Chord) 및 복합 서픽스 완벽 지원**: `A/C#` → `B/D#`, `Em7`, `Cadd9` 등 음악 이론에 따른 정확한 전조.

### 2. 세션 가이드 하이라이트 오버레이
- 찬양팀(드럼, 베이스, 건반, 어쿠스틱/일렉 기타)을 위한 연주 큐 시각화:
  - 🥁 **드럼 in**: 드럼 참여 마디 강조
  - ⚡ **브레이크 (Stop)**: 올스톱 및 피아노 솔로 구간
  - 📈 **빌드업**: 점진적 고조 구간
  - 🔥 **풀 세션**: Full Band 사운드 구간
- **수동 영역 지정**: 악보 위를 마우스로 드래그하여 원하는 위치에 자유롭게 코드나 세션 가이드를 추가/수정/삭제 가능.

### 3. 찬양 콘티 큐 & 슬라이드 관리
- **다중 악보 업로드**: 드래그 앤 드롭으로 악보 이미지 다중 등록.
- **순서 변경**: 예배 콘티 순서에 맞게 실시간 재정렬.
- **브라우저 로컬 저장소(IndexedDB)**: 업로드한 악보와 편집 내용이 브라우저에 안전하게 자동 저장되어 새로고침 후에도 유지됩니다.

### 4. 연주자용 풀스크린 슬라이드 쇼 (PPT 모드)
- **F11 / F 키 전체화면 모드 지원**
- **키보드 / 마우스 컨트롤**:
  - `Space` / `→` / `↓` / `PageDown`: 다음 악보
  - `←` / `↑` / `PageUp`: 이전 악보
  - `H`: 세션 가이드 하이라이트 ON/OFF 토글
  - `ESC`: 슬라이드 쇼 종료

### 5. Gemini AI 브릿지 서버 연동
- OpenAI 호환 규격의 커스텀 브릿지 서버(Tailscale Funnel 등)와 연동하여 악보 분석 및 세션 가이드 자동 생성.
- 오프라인 환경에서도 스마트 로컬 비전 알고리즘이 내장되어 있어 네트워크 없이 100% 정상 작동합니다.

## 🛠️ 로컬 개발 및 실행 방법

### 1. 패키지 설치
```bash
npm install
```

### 2. 환경 변수 설정
`.env.example` 파일을 복사하여 `.env` 파일을 생성하고 필요에 맞게 수정합니다:
```bash
cp .env.example .env
```

```env
# .env
VITE_BRIDGE_BASE_URL=https://your-bridge-server.ts.net/v1
VITE_BRIDGE_API_KEY=dummy-key
VITE_BRIDGE_MODEL=gemini-3.1-pro
```
> **보안 주의**: `.env` 파일은 `.gitignore`에 등록되어 GitHub에 절대 커밋되지 않습니다.

### 3. 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:5173`으로 접속합니다.

### 4. 프로덕션 빌드
```bash
npm run build
```
빌드된 결과물은 `dist/` 폴더에 생성되며, Vercel, Netlify, Cloudflare Pages, GitHub Pages 등에 손쉽게 배포할 수 있습니다.
